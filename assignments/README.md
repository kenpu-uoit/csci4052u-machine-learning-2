## How an assignment differs from a lab

- **It is graded.** There are no CHECK cells telling you that an answer is right; that
  judgement is now yours to make from your own output.
- **You hand in the notebook itself**, run from top to bottom with every output and
  figure left in place. A notebook submitted with its outputs cleared is marked on its
  code alone.
- **Read the assignment's own README first.** It carries the instructions, the mark
  breakdown and the common mistakes.

## Before you start

**Save a copy.** *File → Save a copy in Drive*, before you do any work. Colab discards
everything when the session ends.

**Check whether the assignment needs a GPU.** Its README says so at the top. Where one
is needed: *Runtime → Change runtime type → T4 GPU*, which the free tier provides.
